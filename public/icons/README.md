# CM Interiors PWA icons

Place these PNG files in this directory before building:

- `icon-180.png` — 180×180 PNG for iOS home-screen icons.
- `icon-192.png` — 192×192 PNG for Android and browser install prompts.
- `icon-512.png` — 512×512 PNG for high-resolution install assets.
- `icon-maskable-512.png` — 512×512 PNG with safe padding for adaptive Android icons.

Use the CM Interiors logo on a square canvas. Keep important logo details inside
the central 80% of the maskable icon because mobile launchers may crop its edges.
